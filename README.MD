# NextIA

Projeto de faculdade sobre uma IA que cria uma rotina personalizada para o usuário, de acordo com suas atividades, horários e prioridades.

## Sobre o Projeto

A ideia é permitir que o usuário informe suas atividades, compromissos e horários disponíveis, e o sistema, usando uma IA, gere automaticamente uma rotina organizada para ele.

## Conteúdo do Repositório

- **Caso de Uso** – especificação completa (atores, fluxo principal, fluxos alternativos e de exceção).
- **Diagrama de Caso de Uso** – representação visual dos casos de uso e atores envolvidos.
- **Diagrama de Sequência** – mostra a ordem das mensagens trocadas entre Usuário, Sistema e IA durante a geração da rotina.

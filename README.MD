📐 Diagramas de Casos de Uso — AppAcademia

Este repositório contém três exercícios de Diagramas de Casos de Uso, desenvolvidos utilizando a linguagem PlantUML.

Os diagramas foram elaborados com o objetivo de representar visualmente os atores, funcionalidades do sistema e os relacionamentos entre eles, utilizando conceitos da UML (Unified Modeling Language).

🛠️ Tecnologias utilizadas
PlantUML — criação dos diagramas UML
UML (Unified Modeling Language) — modelagem dos sistemas
GitHub — armazenamento e versionamento dos arquivos
📂 Diagramas
📚 1. App da Biblioteca

O primeiro diagrama representa um sistema de biblioteca, no qual os alunos podem consultar o acervo e realizar reservas de livros.

Principais atores:

👨‍🎓 Aluno
👨‍💼 Bibliotecário

Principais casos de uso:

Pesquisar livros no acervo
Verificar disponibilidade
Reservar livro
Registrar retirada/empréstimo
Registrar devolução

Arquivo:

Diagrama de Casos de Uso - App da Biblioteca.puml

🎬 2. App de Cinema

O segundo diagrama representa um aplicativo de cinema, permitindo aos usuários consultar filmes e realizar operações relacionadas às sessões e ingressos.

Principais funcionalidades:

Consultar filmes
Consultar sessões
Verificar disponibilidade
Comprar/reservar ingressos

Arquivo:

Diagrama de Casos de Uso - App de Cinema.puml

🏋️ 3. App Academia

O terceiro diagrama representa um aplicativo para gerenciamento de uma academia, envolvendo alunos e funcionários da academia.

Principais funcionalidades:

Gerenciar alunos
Consultar informações
Gerenciar atividades
Registrar informações relacionadas aos alunos

🚀 Como visualizar os diagramas

Os arquivos .puml podem ser visualizados utilizando ferramentas compatíveis com PlantUML.

VS Code

Uma opção é utilizar a extensão PlantUML no Visual Studio Code.

Depois de instalar a extensão:

Abra um arquivo .puml.
Abra a visualização do PlantUML.
O diagrama será renderizado automaticamente.
PlantUML Online

Também é possível utilizar um editor online compatível com PlantUML para visualizar os diagramas.

🎯 Objetivo

Este projeto faz parte dos exercícios de modelagem de sistemas utilizando UML, com foco na criação de Diagramas de Casos de Uso.

Através dos diagramas é possível identificar:

Quem interage com o sistema;
Quais funcionalidades o sistema oferece;
Quais são as responsabilidades de cada ator;
Como os casos de uso se relacionam entre si.
